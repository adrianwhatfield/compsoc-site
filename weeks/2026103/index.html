Git Workshop and Challenge

What is git?

Git is an open source version control system used to develop software in large groups. It allows you to track changes in the files and see who made the change. Version control is also useful for solo projects as it allows you to revert changes or track changes you have made to files.

How GitHub is Used

Github is a platform on which you can host your git repos publicly or privatley. This allows you to easily use them across multiple users or devices. Github is free of charge for most projects.

Creating a Git Project

To create a git project locally, go into your project directory and type git init and it will create all the necessary files. To create a project on GitHub, press the add button in the top right and it'll show you a dialogue for creating a project.

Cloning a Repository

To work on a project on GitHub locally you must clone it with the command git clone git@github.com:USERNAME/PROJECT-NAME.git and if you have permission to it will copy the files.

Adding Files to Staged and Committing

Staged files are those that will be included in the next commit, to add them type git add FILE_NAME or git add . to quickly add all changes. To commit these changes, type in git commit -m "COMMIT MESSAGE" and those changed file will be in the history and associated with that message. The purpose of the message is so that other developers know what has changed. git status can be used to give you an overview of which files have been changed and/or staged.

Log and Diff

The log command git log shows committed changed in the repository. The diff command git diff shows the difference between different stages of the repository, for example you can compare two commits, or compare your local repository to the local.

Branches and Merging

A branch is a version of the repository that needs to be edited separately to the main branch, this is usefull when more than one developer is working on a project as it allows them to make changes without effecting the other. A common usage is for bug fixes or new features. The main branch continues on unchanged by the developer, safe from any breaking changes. When the changes are finalised they can be merged into a different branch, typically the main, but it could also be merged into a branch for testing. The command git checkout -b BRANCH_NAME is shorthand for git branch BRANCH_NAME (to create the branch) and git checkout BRANCH_NAME (to switch to it).

To merge a branch, switch to the branch that is going to receive the merge, then use the command git merge BRANCH_TO_BE_MERGED then git will attempt to merge it. There could be a merge conflict which means that both branches have changed the same thing and git doesn't know which version is the correct version. Merge conflicts can be resolved in git in the terminal or on the site the remote repository is hosted on.

Working with HEAD

HEAD refers to the latest commit in the current branch. For example, if you wanted to go to a previous commit that was five above the latest you can type git checkout HEAD~5.

Revert and Reset

Revert and reset are two very similar commands, but revert keeps the commit history and reset doesn't. They are both used to undo commits.

Pulling and Pushing From Remote

Pulling is a combination of fetch and merge, so downloading data and merging it into the working directory. To edit the remote repository locally it must be pulled from the site it is on. This must be done so that you are always editing the latest version of the repository to prevent merge conflicts, but working on a separate branch is ideal in a large project. You can pull using git pull.

A remote repository is when it is hosted on the internet and you can push your committed changes to it. You must have permission to push to it, either because you were added as a collaborator or because you own it. If you would like to commit to a repository that someone else owns, you can fork it and make a pull request that the owner will review and choose to include in the repository or not. Use git push origin BRANCH_NAME.
