SQL Workshop

What is SQL?

SQL (structured query language) is a language for accessing and manipulating databases, which are similar to spreadsheets in structure. It comes it several dialects, that are slightly different but largely follow the same standard. The structure of a query is SELECT * FROM staff; which would select all the columns in the staff table.

Creating a Database

To create a database use CREATE DATABASE db_name; and in different dialects you can see a list of databases, for MySQL it is SHOW DATABASES;.

Creating a Table

Tables live inside of databases and are about one thing, like customers or products. They have a series of columns, which can be of different datatypes.

CREATE TABLE customer (

  customer_id int PRIMARY KEY,

  surname varchar(255) NOT NULL,

  first_name varchar(255),

  email varchar(255),

  age int

);

This table can now be searched through by the database management system (DBMS), added to, or manipulated.

Keys are identifier for columns, a PRIMARY key means that it is a value unique to that row and can't show up again. A FOREIGN KEY is another table's PRIMARY KEY and is used in conjunction with JOINs. For example, a customer order's table might also include the customer ID, so you can work out who made what order.

Inserting Data

Inserting data into a table means adding data to the end, if you have a primary key, it will be generated as the next free number. To insert data, use the queries below.

INSERT INTO table_name (column1, column2, column3, ...)

VALUES (value1, value2, value3, ...);

INSERT INTO table_name

VALUES (value1, value2, value3, ...);

The first syntax is for only adding a row with certain columns filled in (if a user doesn't enter a name, for example) and the second syntax is for adding a row where all of the data for the columns are known.

SELECT Keyword

The SELECT keyword is used for finding data within one or more tables. The syntax is SELECT column1, column2, ... FROM table_name; which will select every row's columns that are named.

SELECT first_name, last_name

FROM customers;

The query above will select every customer's first and last names in the table, if one of the values is null it will say something like NULL, NaN, or be blank.

WHERE Keyword and Operators

The WHERE keyword is how you add specificity to your query. Operators can be used in combination with it, they are: =, >, <, <> (not equal), BETWEEN, LIKE, and IN.

SELECT first_name, age

FROM customers

WHERE age >= 18

AND first_name LIKE 'J%';

The query above would select all the customers who are more than or equal to 18 years old and first name begins with 'J'. You can include more than this amount of conditions, but each one after the first must start with AND.

Deleting and Change Data

To delete or change data from a table and if you don't want to alter every row in a table, you need to include a WHERE keyword. The syntax for deletion is DELETE FROM table_name WHERE condition;. For updating/changing data it is:

UPDATE table_name

SET column1 = value1, column2 = value2, ...

WHERE condition;

Aggregate Functions

Aggregate functions apply a calculation to a column or section of a columns and return the value. There are five of them: MIN, MAX, COUNT, SUM, and AVG. In order to use them, they are usually combined with an GROUP BY clause so the results, so they are split into categories.

SELECT department_name, AVG(salary)

FROM staff

GROUP BY department_name;

This would show the average salary per department.

SELECT gender, MAX(age)

FROM customer

GROUP BY gender;

This would show the maximum age for different genders of the customers.

SELECT author, COUNT(title)

FROM articles

GROUP BY author;

This would show the number of articles in the table by each author.

JOINs

JOINs can combine multiple tables into one query for the use of data analysis. To join two tables, they need to have a column in common (typically an ID), this is a FOREIGN KEY.

SELECT c.last_name, o.product_name

FROM customers c

JOIN orders o ON c.customer_id = o.customer_id;

The above query would show all the customer's surnames and the product they bought's name. When joining, use ON to show what the two tables have in common. To join more tables, just add another line, you can chain JOINs. IF the orders table included a staff ID, you could join to the staff table and get their data too.
