# Weeks Folder...

Please create any weekly resources in a folder with the corresponding year, semester and week no in the format YYYYSWW note that the year should be the start of the respective academic year

- For instance Semester 1 week 1 2026/27 would be in the folder `./2026101/`

- Semester 2 week 12 2027/28 would be in the folder `./2027212` despite the session actually being held in the 2028 calendar year

***Thank you for helping us keep organised***
