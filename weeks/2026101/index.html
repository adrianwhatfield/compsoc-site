Programming Challenges

Below are ten challenges that can be completed in any language. We encourage you to work in teams.

For help with coding, you can go to W3Schools.

Challenge One: Bank Card Number Validator

Card numbers follow certain rules and algorithms can be written to check a number against these rules. Find them out and implement them.

Challenge Two: Text Adventure Game

Make a text adventure game, it can complex or as simple as you wish it to be.

Challenge Three: Sieve of Eratosthenes

This is an algorithm for finding all of the prime numbers up to a given limit, implement it.

Challenge Four: 2D Trajectory Calculator

Calculate the trajectory for a given set of inputs, then output the values of the trajectory or an image.

Challenge Five: Roman to Decimal Converter

For a given string of a Roman numeral, output the correct decimal number. For example, XI -> 11. You can also do the inverse if you wish to.

Challenge Six: Password Complexity Calculator

Output how strong a password is based off of common factors such as length and special characters.

Challenge Seven: ASCII Art Run Length Encoding

Run length encoding is a type of data compression where a symbol is created and the encoder stores this as how many times the symbol is repeated. For instance:
## ## #### #######
## ## # #
## ### #
## # #
## #### ##

Becomes:
#2 2#2 3#4 2#7
1#2 1#2 2#1 9#1
2#2 5#3 6#1
1#2 9#1 5#1
#2 6#4 4#2

In this challenge you should create a python script that can encode and decode some ascii art. You may want to make assumptions such as the same charecter is not repeated more than 9 times.

Challenge Eight: Merge Sort Algorithm

Implement a merge sort algorithm.

Challenge Nine: Fizz Buzz

For all numbers from 0 to n, output the number, fizz, buzz, or fizzbuzz if the number is divisible by 3, 5, neither or both.

Challenge Ten: Brightest of Two Hex Colours

Take in two hexcode numbers and output the one which would be brighter.
